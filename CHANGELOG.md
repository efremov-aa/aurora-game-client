# CHANGELOG — Aurora Game

Все значимые изменения клиента Aurora Game (Discord-подобный игровой мессенджер).
Пишет их сам котик Аврора: сначала коротко мурчит, потом честно перечисляет, что
поменялось. Старые записи не удаляются — это дневник, а не черновик.

## [1.4.50] — «Микрофон на связи»: иконка больше не залипает, голос в общем канале ожил

Котёнок починил то, из-за чего голосовой экран врал о микрофоне. Кнопка «Включить микрофон»
на самом деле глушила дорожку: обработчик просто переворачивал флаг `STATE.muted`, а дорожка
при этом не публиковалась. Человек нажимал — иконка оставалась перечёркнутой, звука не было.

### Клиент
- Микрофон считается включённым только когда сходятся три вещи: есть подключение к комнате,
  дорожка реально опубликована и звук не приглушён. Одно место правды — `voiceMicIsOn()`,
  им пользуются и док, и кнопка в профиле, и модель комнаты (`voiceRoomModel().micOn`)
- Первое нажатие в канале публикует дорожку (`voiceEnableMic()`), а не глушит её; повторное —
  штатно снимает и ставит mute, не пересоздавая дорожку
- Отказ в доступе к микрофону показывается честно: причина уходит в тост, иконка не врёт,
  будто микрофон включён
- Включение микрофона при активном deafen снимает и «глухоту», иначе звук остался бы выключен
- Новый набор `tests/test_voice_mic_toggle.js` — 7 сценариев (нет подключения, первая
  публикация, mute, unmute, deafen, матрица `voiceMicIsOn`, отказ в доступе), входит в `npm test`

### Сервер
- `livekit.yaml` приведён к ключам из `data/game_media.json` — тем самым, которыми `gamehub`
  подписывает токены. Раньше SFU знал один ключ, а токены шли с другим, отсюда `invalid api key`
- Перезапущен только SFU; TLS/WebSocket-прокси Caddy не трогали. Бэкап прежнего конфига рядом
- Юниты автозапуска (`aurora-livekit-sfu`, `aurora-livekit-wss`) уже были включены — после
  перезагрузки голос поднимается сам

### Проверено
- Живой вход с новым ключом: `connected=true`, комната `aurora-voice-e2e-verify`,
  `micPublished=true`, ошибки `invalid api key` нет
- `npm test` — 10 наборов, все зелёные
- Скриншоты до/после нажатия: перечёркнутая кнопка и бейдж `micOff` исчезают
- `AuroraGame-Setup-1.4.50.exe` не коммитится: он весит больше лимита GitHub, только ассет

## [1.4.49] — Кот-диджей: голосовой экран как в Discord

Котик переставил мебель в голосовом канале: шапка стала живой, участники — плитками,
а кнопки собрались в нижний док. Один компонент теперь работает на трёх сценариях.

### Новое
- Единый голосовой экран `voiceShellMarkup()` для трёх сценариев: голосовой канал сервера, канал сообщества и страница «Голос и видео»
- Шапка канала: иконка, имя, пилюля «на связи», таймер звонка и пинг с индикатором качества
- Сцена плиток: круглые аватары с зелёным кольцом говорящего, бейджи mute/камера/экран, видео-плитка крупнее остальных
- Нижний док: микрофон, звук, камера, демонстрация экрана и одна большая кнопка «Подключиться» / «Отключиться»
- Иконки — inline SVG, а не эмодзи: одинаково выглядят в любой теме

### Изменено
- `voiceSurfaceSync()` больше не перерисовывает весь блок зря: сверяет подпись `data-vc-sig` и точечно правит таймер, пинг и подсветку говорящего
- Присутствие и медиа разделены: вход в канал показывает экран сразу, а микрофон запрашивается только кнопкой дока
- `lk.js`: глушение вывода звука (`setDeafened`) и сброс `<audio>` при выходе

### Исправлено
- `index.html` приведён к LF — тест `test_community_session.js` снова видит контракт `communitySyncProfile`
- Комментарий CSS ссылался на несуществующую `voiceSurfaceMarkup()` — теперь `voiceShellMarkup()`

### Честно
- Видео-плитка на тестовом стенде была чёрной: `attachVideos` в моке заглушен; в приложении `srcObject` ставит `lk.js`
- Экран проверен на 1360, 760 и 620 px: шапка не переполняется, сцена не уходит под док
- Установщик `AuroraGame-Setup-1.4.49.exe` (129 МБ) лежит только в ассетах релиза, в git его нет

## [1.4.48] — Кот-обновлятор: скачал, поставил, перезапустился

Котик устал объяснять людям, куда распаковывать архив. Теперь он делает всё сам:
проверил, скачал, сверил SHA-256, заменил файлы и вернулся с новым бантом.

### Новое
- **Полный цикл автообновления**: проверка версии → скачивание → сверка SHA-256 → распаковка → замена файлов → перезапуск приложения
- `github-updater.js::prepareUpdate()` — скачивает `AuroraGame-win32-x64.zip` и распаковывает его через `Expand-Archive` во временную папку профиля
- Служебный `update.bat`: ждёт закрытия `AuroraGame.exe`, при необходимости завершает процесс, копирует файлы через `robocopy /E`, запускает игру заново и убирает за собой архив с временными папками
- `findAppDir()` — если архив распаковался с вложенной папкой, котик находит `AuroraGame.exe` и копирует из правильного места
- IPC-канал `aurora:update-apply` и `window.aurora.updateApply()` в preload
- Кнопка «Обновить и перезапустить» во вкладке **Настройки → 📦 Обновления**
- Автопроверка обновлений при старте: если версия новее, кнопка установки видна сразу

### Честно
- Если GitHub недоступен, игра не падает: котик сообщает, что проверка не удалась, и работает дальше
- Защита от гигантских архивов осталась: апдейтер не примет файл больше 350 МБ

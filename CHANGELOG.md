# CHANGELOG — Aurora Game

Все значимые изменения клиента Aurora Game (Discord-подобный игровой мессенджер).

## [1.4.44] — Публичный релиз, автообновление, установщик

### Новое
- **GitHub-репозиторий клиента**: https://github.com/efremov-aa/aurora-game-client
- **Автообновление через GitHub Releases** — проверка версии, скачивание архива с SHA-256 верификацией, вкладка «Обновления» в настройках
- **Inno Setup установщик** — `installer/install.iss`, собирает `AuroraGame-Setup.exe`
- **README.md** — полное описание проекта на русском и английском
- **VOICE_SERVER.md** — документация по медиасерверу

### Исправления
- Убраны хардкод выдуманных портов в карточке участника — порты берутся из реальных данных узла
- Исправлен дубликат функции `renderSettingsTab` в `index.html`
- Исправлена опечатка во вкладке обновлений
- Исправлена обработка вкладки «Обновления» в `renderSettingsTab`

### Технологии
- Electron 45.2.1
- LiveKit 1.13.11 (голос, видео, экран)
- Node.js + SQLite (серверная часть)
- GitHub Releases (автообновление)

## [1.4.43] — Системный трей, автозапуск, безопасность

### Новое
- Системный трей Windows — крестик скрывает окно, не закрывает приложение
- Автозапуск вместе с Windows (свёрнутым в трей)
- Проверка безопасности локального API: Host, Origin, Sec-Fetch-Site, защита от iframe
- Восстановление личных диалогов после перезапуска
- Поддержка тредов сообщений
- Система друзей: поиск, заявки, принятие/отклонение, список друзей, удаление
- Блокировка профилей: скрытие из поиска и присутствия, закрытие личных сообщений и вложений
- Роли и модерация пользовательских каналов
- Публичные серверы: создание, вступление, выход, изменение оформления
- Вложения в общий чат и DM (до 1 МБ)
- Сезонные темы: авто по календарю, Хэллоуин, Новый год, весна, лето
- Выбор аватара профиля, синхронизация ника, цвета, описания через игровой профиль
- Локальный режим без панели: прямые серверы, локальные заметки, импорт/экспорт JSON

### Исправления
- Исправлен SyntaxError в `communityStart()` — пустое окно клиента
- Исправлен дубль профиля в списке участников
- Исправлено перекрытие статуса аватарки
- Исправлен баг восстановления истории при смене профиля
- Исправлен импорт игрового профиля — неверный ключ не удаляет текущий
- Исправлено переключение голосовых комнат
- Исправлена привязка многошаговых действий к исходному профилю
- Исправлено удаление камеры/микрофона при отказе публикации
- Исправлен XSS в динамических ID и значениях интерфейса
- Защита локального API от DNS rebinding и CSRF

### Тесты
- 8 npm-тестов: community-cursor, livekit, window-security, inline-handlers, localserver-security, community-session, community-dm-state, community-proxy, community-token-store
- 24 Python-теста API
- 7 проверок разметки

## [1.4.38] — Треды сообщений

- Треды хранятся на сервере, загружаются у всех участников

- Клиент сам ищет панель в локальной сети
- Если панель не найдена — автоматическая проверка публичного сервера по HTTPS

## [1.4.31] — Голосовой endpoint в игровом API

- Игровой API читает конфигурацию LiveKit и создаёт подписанный медиатокен для голосовых каналов
- Секрет LiveKit не попадает в клиентскую сборку

## [1.4.25] — Безопасность окон Electron

- Проверка разрешений требует точный локальный origin и текущий порт
- Внешние ссылки открываются в системном браузере
- Дочерние окна и переходы на сторонние страницы блокируются

## [1.4.15] — Журнал изменений сообщений

- Новые сообщения, правки, удаления и реакции передаются как обновления
- При первом подключении загружается снимок истории

## [1.4.13] — Переключение игровых профилей

- Импорт проверяет ключ у сервера — неверный ключ не удаляет текущий
- Зашифрованное хранилище держит отдельный ключ для каждого сервера
- При смене сервера или аккаунта очищается приватный кэш личных сообщений

## [1.4.12] — Восстановление личных диалогов

- Возвращает собеседников и последнее сообщение даже при офлайне собеседника
- Входящие изолированы по аккаунту

## [1.4.11] — Проверка сервера

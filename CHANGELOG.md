# CHANGELOG — Aurora Game

Все значимые изменения клиента Aurora Game (Discord-подобный игровой мессенджер).

## [1.4.44] — 01.11.2026 — Публичный релиз, автообновление, установщик

### Новое
- **GitHub-репозиторий клиента**: https://github.com/efremov-aa/aurora-game-client
- **Автообновление через GitHub Releases** — проверка версии, скачивание архива с SHA-256 верификацией, вкладка «Обновления» в настройках
- **Inno Setup установщик** — `installer/install.iss`, собирает `AuroraGame-Setup-1.4.44.exe`
- **README.md** — полное описание проекта на русском и английском
- **SETUP_VOICE_MASTER.md** — инструкция по настройке голосового сервера LiveKit на макрое
- **VOICE_SERVER.md** — документация по медиасерверу, портам, сертификатам

### Исправления
- Убраны хардкод выдуманных портов (27015/25565/27016/27017) в карточке участника — порты берутся из реальных данных узла `u.ports`
- Исправлен дубликат функции `renderSettingsTab` в `index.html`
- Исправлена опечатка `appVersion` → `APP_VERSION` во вкладке обновлений
- Исправлена обработка вкладки «Обновления» в `renderSettingsTab`

### Технологии
- Electron 45.2.1
- LiveKit 1.13.11 (голос, видео, экран)
- Node.js + SQLite (серверная часть)
- GitHub Releases (автообновление)

### Статус автообновления
Код реализован и влит в master, но **не функционирует пока не создан GitHub Release** с ассетом `AuroraGame-win32-x64.zip`. См. инструкцию ниже в разделе «Готовность к релизу».

## [1.4.43] — 31.10.2026 — Системный трей, автозапуск, безопасность

### Новое
- Системный трей Windows — крестик скрывает окно, не закрывает приложение
- Автозапуск вместе с Windows (свёрнутым в трей)
- Проверка безопасности локального API: Host, Origin, Sec-Fetch-Site, защита от iframe
- Восстановление личных диалогов после перезапуска (`/game/dms`)
- Поддержка тредов сообщений (`/game/threads` GET/POST)
- Система друзей: поиск, заявки, принятие/отклонение, список друзей, удаление
- Блокировка профилей: скрытие из поиска и присутствия, закрытие личных сообщений и вложений
- Роли и модерация пользовательских каналов: владелец назначает модератора, жалобы на сообщения
- Публичные серверы: создание, вступление, выход, изменение оформления (имя, описание, эмодзи)
- Вложения в общий чат и DM (JPEG, PNG, GIF, WebP, PDF, TXT до 1 МБ)
- Сезонные темы: авто по календарю, Хэллоуин, Новый год, весна, лето
- Выбор аватара профиля, синхронизация ника, цвета, описания через игровой профиль
- Локальный режим без панели Aurora: прямые серверы, локальные заметки, импорт/экспорт JSON

### Исправления
- Исправлен SyntaxError в `communityStart()` — пустое окно клиента
- Исправлен дубль профиля в списке участников (игровой аккаунт исключён из списка остальных)
- Исправлено перекрытие статуса аватарки — сезонный значок перенесён наверх
- Исправлен баг восстановления истории при смене профиля — курсоры разделены по серверу/профилю/комнате
- Исправлен импорт игрового профиля — неверный ключ не удаляет текущий
- Исправлено переключение голосовых комнат — проверка совпадения комнаты, SFU и identity
- Исправлена привязка многошаговых действий к исходному профилю (вложения, роли, жалобы, дружба, блокировки)
- Исправлено удаление камеры/микрофона при отказе LiveKit публикации
- Исправлен XSS в динамических ID и значениях интерфейса — JSON-литералы с безопасным HTML-экранированием
- Защита локального API от DNS rebinding и CSRF

### Тесты
- 8 npm-тестов: community-cursor, livekit, window-security, inline-handlers, localserver-security, community-session, community-dm-state, community-proxy, community-token-store
- 24 Python-теста API
- 7 проверок разметки

## [1.4.35] — Автопоиск панели Aurora

- Клиент сам ищет Aurora в локальной IPv4-сети на порту 8890
- Ошибочный порт 8899 (прокси Xray) распознаётся и не используется
- Если локальная панель не найдена — автоматическая проверка мастера по HTTPS

### Что нужно сделать для публикации релиза

1. **Собрать portable-архив** (Windows):
   ```powershell
   cd electron
   .\build-portable.ps1
   ```
2. **Запаковать в `AuroraGame-win32-x64.zip`** (точно такое имя)
3. **Создать GitHub Release** с тегом `v1.4.44` и ассетом ZIP
4. **Собрать установщик** (опционально):
   ```powershell
   & 'C:\Program Files\Inno Setup 7\ISCC.exe' installer/install.iss
   ```
5. **Создать `game_media.json` на макрое** для работы внешнего голоса/видео
